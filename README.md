# 📚 Student Manager

یک برنامه‌ی خط فرمان برای مدیریت دانشجوها با پایتون.

## ✨ قابلیت‌ها
- افزودن، حذف، جستجو و نمایش دانشجو
- محاسبه معدل فردی و کل کلاس
- ذخیره‌سازی در فایل JSON
- اعتبارسنجی ورودی‌ها
